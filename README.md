# MovieRama

`Typescript` `SCSS` `rollup.js` `Jest.js` `Node version: 18.18.2`

Live demo at [vercel](https://frontend-movie-rama-vasilis-tziatzias.vercel.app/)

## Installation proccess

`npm install` to install dependencies

`npm start` build project bundles, run tests, and start the localhost server `localhost:3000`

## User flow

-   **Now Playing:** List all movies now playing, grouped by 20, and load more once you reach the end of the page.
-   **Movie Details:** Render information about specific movie, trailers, reviews (if the movie has more than 1), and Recommended movies.
-   **Search Movies:** Users can start typing and searching for the desired movie.
